# Atividade Técnica — ESIG

Este repositório contém a solução desenvolvida para a atividade técnica da ESIG.

## Sobre o projeto

A aplicação foi criada com o objetivo de atender aos requisitos propostos no desafio, demonstrando organização, boas práticas de desenvolvimento e funcionamento das principais funcionalidades solicitadas.

## Funcionalidades

- Implementação dos requisitos da atividade técnica;
- Organização do código e dos arquivos do projeto;
- Interface e/ou funcionalidades necessárias para a utilização da aplicação.

## Como executar

1. Clone este repositório:

	```bash
	git clone <URL_DO_REPOSITORIO>
	```

2. Acesse a pasta do projeto:

	```bash
	cd <NOME_DA_PASTA>
	```

3. Execute:
	```bash
	docker compose up -d
	```


## Observações

Este Projeto foi desenvolvido exclusivamente para fins de avaliação da atividade técnica da ESIG.
